# Event Analyzer

## Overview

Event Analyzer is a Python application designed to analyze event log data stored in a JSON file.

The program loads event records into a Pandas DataFrame and generates a detailed report showing:

- Total number of events
- Event status statistics
- Event counts per user
- Average event duration
- Longest-running event
- Failed events

This project was developed as a practical exercise to strengthen Python programming, data analysis, file handling, documentation, and software design skills.

---

## Features

### Event Counting
Calculates the total number of events contained in the dataset.

### Status Analysis
Displays the number of successful and failed events.

### User Activity Analysis
Counts how many events were generated by each user.

### Duration Analysis
Calculates the average duration of all recorded events.

### Longest Event Detection
Finds the event with the highest duration.

### Failed Event Reporting
Filters and displays all failed events.

### Console Banner
Displays an Event Analyzer banner using the PyFiglet library.

## Function Breakdown

### count_events()

Purpose:
Counts the total number of events contained in the dataset.

Output:
Total Number of Events

---

### count_by_status()

Purpose:
Counts events grouped by status.

Example:

successful : 15
failed : 3

---

### count_by_user()

Purpose:
Counts the number of events generated by each user.

Example:

Alice : 5
Bob : 8
John : 2

---

### calculate_average_duration()

Purpose:
Calculates the average event duration.

Example:

Average Event Duration: 5.20 seconds

---

### find_slowest_event()

Purpose:
Identifies the event with the longest execution time.

Displays:

- User
- Action
- Duration

---

### get_failed_events()

Purpose:
Displays all events that contain a status of "failed".

---

### display_banner()

Purpose:
Displays the application title using ASCII art.

---

### main()

Purpose:
Controls the execution of the entire application.

Responsibilities:

- Load JSON file
- Display preview data
- Call analysis functions
- Handle exceptions

## Input Format

The program expects an events.json file.

Example:

[
    {
        "user": "Alice",
        "action": "Login",
        "duration": 4,
        "status": "success"
    },
    {
        "user": "Bob",
        "action": "Upload",
        "duration": 10,
        "status": "failed"
    }
]
